# Student Performance Statistical Analysis

## Project Description
This project analyzes student performance data using statistical methods.  
It includes data cleaning, descriptive statistics, F-test analysis, and graphical visualizations to understand student performance trends.

## Dataset
The dataset contains information about students, including:
- Academic scores
- Attendance
- Demographic information

## Features
- Data cleaning and preprocessing
- Calculation of descriptive statistics (mean, median, variance)
- F-test for variance analysis
- Plotting graphs for better visualization
- Easy-to-understand statistical reports

## Tools Used
- Python (Pandas, Matplotlib, Seaborn, NumPy)
- Git & GitHub for version control
